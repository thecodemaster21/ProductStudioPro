# Product Studio Pro 5.2.0

A focused Blender workflow from product setup to final render.

- Five studio presets: automotive, watch, perfume, headphones and packaging.
- Adjustable reflection cards with gradient and color controls.
- Hero, Macro, Beauty 45° and Side Profile camera presets.
- Beauty, clay, wireframe and transparent outputs across one or all scene cameras.
- THAR ROXX and headphone material libraries, import helpers and asset preparation tools.

This GitHub preparation adds documentation, a visual feature preview, reproducible packaging and automated source checks. It also fixes Hero camera activation, first-use concrete material assignment and all-camera selection.

**Install:** Download `ProductStudioPro-5.2.0.zip`, then use Blender's **Preferences → Add-ons → Install from Disk**. Enable the add-on and open **3D Viewport → N → Product Studio**.

**Compatibility:** Declared minimum Blender 5.1.0; verified by focused smoke checks on Blender 5.1.2/macOS. See `docs/VALIDATION.md` for coverage and limitations.
